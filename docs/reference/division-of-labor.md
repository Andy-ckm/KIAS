## 分工机制

### MiniMax(前台协调)
1. **监控**: 每30分钟检查编译/测试/clippy状态
2. **审核**: 每小时审核未提交代码
3. **分析**: 分析问题并生成修复建议
4. **汇报**: 向零汇报进度

### mimo(后台开发)
1. **修复**: 根据MiniMax建议修复编译错误
2. **开发**: 实现新功能
3. **测试**: 确保测试通过
4. **清理**: 清理unwrap/println
