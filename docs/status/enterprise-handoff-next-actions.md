## 1. 按 A~I 的“完成定义（DoD）+ 立即行动”

> 说明：以下不是再列愿景，而是“必须做出的可验收交付物”。

## A. Reliability Kernel（绝不翻车）

### A1 统一生命周期监督
- DoD
  - 所有服务统一暴露：启动状态、优雅停机、重启原因、退避次数、熔断状态。
  - 至少 72h 稳定运行压测下，无人工干预自恢复成功率 ≥ 99.9%。
- 立即行动
  - 抽取统一生命周期 trait（start/probe/drain/shutdown/recover）。
  - 增加 `restart_reason` 与 `backoff_stage` 指标。

### A2 健康模型四态（Liveness/Readiness/Degraded/Draining）
- DoD
  - 健康端点返回四态枚举，不再只 bool。
  - 网关根据状态自动摘流/恢复。
- 立即行动
  - 扩展健康检查协议；补充流量切换 e2e 测试。

### A3 控制面/数据面隔离
- DoD
  - 任一面故障注入 30 分钟，另一面核心SLO不破。
- 立即行动
  - 资源配额、连接池、队列、线程池分离。

### A4 超时+重试预算+舱壁
- DoD
  - DB/etcd/model gateway 全部有显式 timeout 与 retry_budget。
  - 禁止无限重试；出现雪崩时自动退让。
- 立即行动
  - 建立依赖策略清单（每依赖一页策略表）。

### A5 幂等与去重
- DoD
  - API/任务/回调/重试全链路具备 idempotency-key。
  - 重放测试1000次，副作用计数保持 1。

### A6 一致性策略矩阵
- DoD
  - 每类流程标注 Strong/Eventual/Compensation。
  - 补偿动作可自动执行并可审计。

### A7 故障注入框架
- DoD
  - 支持网络抖动、节点宕机、慢盘、慢查询、随机异常五类注入。
  - Nightly 自动跑，失败自动开 issue。

### A8 DR 演练
- DoD
  - 备份/恢复/校验/回放全自动。
  - 固化 RTO/RPO 报告（周报可追溯）。

### A9 发布可回滚
- DoD
  - 蓝绿/金丝雀/影子流量至少落地一种并自动回滚。

### A10 零损滚更
- DoD
  - 连接迁移、任务漂移、checkpoint兼容三项自动验收通过。

## B. Governance-by-Design（可证明）

### B1 Decision Record
- DoD
  - 每次调度/路由/自治决策有记录：输入、候选、权重、结果、置信度。
  - 支持按 trace_id 追溯完整决策链。

### B2 Policy as Code
- DoD
  - 策略版本化、可审查、可回滚、可差异对比。

### B3 策略模拟器
- DoD
  - 上线前能回放历史流量，对比新旧策略误伤率/成本/延迟。

### B4 合规闸门
- DoD
  - PII、敏感操作审批、越权阻断强制生效并留证据。

### B5 不可抵赖审计链
- DoD
  - 签名+哈希链+时间戳+篡改检测四项齐全。

### B6 追责图谱
- DoD
  - “谁在何时基于何证据做何决定”可秒级查询。

### B7 自主度动态降级
- DoD
  - 高风险场景自动从 FullAuto 降级到 AutoEdit/Suggest。

### B8 输出可信度
- DoD
  - 事实核验、冲突检测、引用完整性、幻觉分级可度量。

### B9 红队库
- DoD
  - 注入/越权/外泄/供应链污染回归用例进入 CI。

### B10 审计可视化
- DoD
  - 决策时间线、证据回放、报告导出三项可用。

## 3. Agent 执行模板（强制）

每个整改任务必须提交以下字段：

- 目标（解决什么问题）
- 验收标准（量化指标）
- 改动范围（crate/模块/API/配置）
- 验证证据（命令+结果+指标+截图/日志）
- 回滚方案（失败如何恢复）
- 风险与依赖（影响范围）

## 4. 交付标准（本文件对应）

当以下条件满足，才能声称“企业可用”：

- 连续多轮稳定通过质量门禁。
- 关键故障演练与恢复可复现。
- 决策链可追溯且不可抵赖。
- 多租户安全边界经压测与攻防验证。
- 性能/成本/可用性达到目标阈值并可持续监控。
