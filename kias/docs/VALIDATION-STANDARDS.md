# AgentGuard 10 维度商业验证标准

## 评分标准（≥85% 可上线，≥70% 可内测）

| 维度 | 权重 | 当前 | 目标 |
|------|------|------|------|
| 1. 功能完整性 | 15% | 60% | 90% |
| 2. 测试覆盖率 | 15% | 40% | 80% |
| 3. 代码质量 | 10% | 70% | 90% |
| 4. 安全性 | 10% | 50% | 85% |
| 5. 性能 | 10% | 60% | 85% |

| 10. AI 治理 | 10% | 55% | 85% |

## 测试标准（业内最严格）

1. 行覆盖率 ≥ 80%
2. 分支覆盖率 ≥ 70%
3. 测试类型：单元 + 集成 + 边界 + 错误路径 + 并发
4. 禁止：unwrap()、死代码、未测分支
5. GxP：审计追踪、数据完整性、变更控制
