## 四、核心能力分析

1. **MQTT 协议**: 3.1/3.1.1/5.0、QoS 0/1/2、共享订阅、遗嘱消息
2. **认证授权**: MySQL/PostgreSQL/MongoDB/Redis/HTTP/LDAP/JWT/OAuth2.0/SCRAM
3. **规则引擎**: SQL 语法、jq 函数、实时数据处理
4. **数据集成**: 30+ 连接器（Kafka/RabbitMQ/Pulsar/各种数据库）
5. **网关**: MQTT-SN/CoAP/LwM2M/STOMP/ExProto
6. **监控**: Prometheus/Grafana/StatsD/Datadog、审计日志、实时追踪
7. **安全**: TLS/mTLS/PSK、IP 白名单、客户端 ID 限制
8. **部署**: Docker/K8s/RPM/DEB、集群自动发现

## 五、AgentGuard 的超越机会

EMQ 做的是数据传输层，AgentGuard 做的是治理层。
EMQ 的客户已经有了数据管道，现在缺 Agent 动作的合规治理。

AgentGuard 超越路线:
1. **EMQ 管数据流，AgentGuard 管 Agent 行为** — 互补而非竞争
2. **EMQ 的 13 个行业 = AgentGuard 的 13 个目标行业** — 共享客户池
3. **EMQ 已经教育了市场** — 客户已理解 IoT/Agent 的重要性
4. **AgentGuard 的差异化**: GxP/FDA 合规、审计追踪、自主度控制
5. **EMQX 6.2 的 A2A over MQTT** — Agent 间通信已有协议，AgentGuard 补治理层
