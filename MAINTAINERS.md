## Responsibilities

Maintainers are expected to:

- review and merge changes based on evidence and project scope;
- keep CI, security scanning, dependencies, and releases healthy;
- respond to security and privacy reports through the private process;
- protect repository credentials and require strong account security;
- avoid committing employer, customer, partner, tenant, internal-system, or personal information;
- publish clear release notes and migration guidance;
- support reviewers and develop new maintainers;
- disclose relevant conflicts of interest.

## Contact

Use public issues and discussions for ordinary project questions. Use GitHub private security advisories for vulnerabilities, credential exposure, privacy incidents, or sensitive reports.

No personal email address is published in this file by design.
